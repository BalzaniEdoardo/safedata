# Writing rules for this repository: prose in docs, code comments, docstrings
# and user-facing strings. Checked by tools/style/check.py.
#
# One regex per line, matched case-insensitively. In markdown, ^ anchors the
# start of a line (use it for headings). Code blocks and `inline code` in
# markdown are not checked. Lines starting with # are comments.
#
# [hard]  Never allowed. The check fails and the text must be rewritten.
# [soft]  Allowed only when the words are meant literally ("the shop pays for
#         the delivery"). Every new match must be reviewed. To accept a literal
#         use for good, put `style: allow` on the same line (in a comment).
#
# Built-in hard rule: in markdown, each paragraph and each list item is a
# single line (no hard wrapping).
#
# The rules are examples of a register, not a complete list: prose that is
# close in style to a banned phrase should be rewritten too.
